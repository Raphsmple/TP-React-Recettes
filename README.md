# TP React Recettes

Application web réalisée avec React et TypeScript permettant de consulter des recettes de cuisine.

## Installation

Après avoir décompressé le projet, installer les dépendances avec :

```bash
npm install
```

## Lancer le projet

Pour lancer le serveur de développement :

```bash
npm run dev
```

Puis ouvrir l'adresse indiquée dans le terminal
```

## Commandes utiles

### Lancer le projet

```bash
npm run dev
```

### Vérifier que le projet fonctionne et créer le build

```bash
npm run build
```

## Fonctionnalités

* Page d'accueil
* Affichage de toutes les recettes
* Affichage du détail d'une recette
* Filtrage des recettes par catégorie
* Navigation entre les différentes pages
* Page 404 pour les pages inexistantes
* Interface responsive avec Tailwind CSS
